📋 云端服务注册指南
JSONBin.io（推荐，最简单）
1. 打开 https://jsonbin.io
2. 注册账号（邮箱即可）
3. 点 Create a Bin → 随便输入{} → Create
4. 复制 Bin ID 和 API Key
5. 填入上方对应输入框

Supabase（功能更强）
1. 打开 https://supabase.com
2. 注册 → New Project
3. SQL Editor 执行：
CREATE TABLE sync_data(room TEXT PRIMARY KEY,data JSONB);
4. Settings → API → 复制URL和anon key
5. 填入上方对应输入框
